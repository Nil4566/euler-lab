⑤ Algorithm

  1. รับ f, x₀, y₀, h, x_end
  2. n = round((x_end − x₀)/h)
  3. for k = 0 … n−1:
  4.   s = f(x_k, y_k)
  5.   y_{k+1} = y_k + h·s
  6.   x_{k+1} = x_k + h
  7. return y_n ≈ y(x_end)

✅ ข้อดี

  • เข้าใจง่าย เขียนโปรแกรมง่าย
  • ใช้ f แค่ 1 ครั้งต่อ step (เร็ว)
  • เป็นพื้นฐานของ Heun, RK4

⚠️ ข้อเสีย

  • แม่นยำต่ำ (first-order, O(h))
  • ต้องใช้ h เล็กมากถึงจะแม่น → คำนวณหลายรอบ
  • error สะสมไปเรื่อยๆ ทุก step

🔎 ข้อควรระวัง

  • Stability: y' = −λy ต้องใช้ h < 2/λ ไม่งั้นค่าแกว่ง/ระเบิด
  • ถ้า (x_end−x₀)/h ไม่ลงตัว จะไปไม่ถึง x_end พอดี
  • ใช้ค่าละเอียดในการคำนวณ ปัดเฉพาะตอนแสดงผล
  • ระวังจุดที่ f ไม่นิยาม (หารศูนย์, √ ค่าลบ)
